# Coroa de Ferrugem

Versões do jogo (Windows). O código não fica aqui.

- **Para instalar:** baixe o [instalador em .zip](https://github.com/sergioveiga10/coroa-de-ferrugem/raw/main/instalador/CoroaDeFerrugem_Instalador_0.14.0.zip), extraia e execute o `CoroaDeFerrugem_Instalador_0.14.0.exe` que está dentro. O .zip existe porque alguns navegadores bloqueiam o download direto de .exe sem assinatura. O .exe solto também está na pasta `instalador/`.
- **Atualizações:** o jogo verifica sozinho ao abrir, baixa só o que mudou e aplica na próxima vez que for aberto.
- **Aviso do Windows** ("O Windows protegeu o computador"): clique em *Mais informações* e depois em *Executar assim mesmo*. O instalador não tem assinatura digital.
