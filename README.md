# Coroa de Ferrugem

Versões do jogo (Windows). O código não fica aqui.

- **Para instalar:** abra a aba [Releases](https://github.com/sergioveiga10/coroa-de-ferrugem/releases), baixe o arquivo `CoroaDeFerrugem_Instalador_X.exe` mais recente e execute.
- **Atualizações:** o jogo verifica sozinho ao abrir, baixa só o que mudou e aplica na próxima vez que for aberto.
- **Aviso do Windows** ("O Windows protegeu o computador"): clique em *Mais informações* e depois em *Executar assim mesmo*. O instalador não tem assinatura digital.
