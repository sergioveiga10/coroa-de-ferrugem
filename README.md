# A Coroa dos Dois Reinos

Versões do jogo (Windows e web). O código não fica aqui.

- **Para instalar no Windows:** baixe o [instalador em .zip](https://github.com/sergioveiga10/coroa-de-ferrugem/raw/main/instalador/A_Coroa_dos_Dois_Reinos_Instalador_0.16.0.zip), extraia e execute o `A_Coroa_dos_Dois_Reinos_Instalador_0.16.0.exe`. O .zip existe porque alguns navegadores bloqueiam o download direto de .exe sem assinatura. O instalador remove a versão antiga ("Coroa de Ferrugem") e mantém os saves.
- **Jogar no navegador:** https://sergioveiga10.github.io/coroa-de-ferrugem/
- **Atualizações:** o jogo verifica sozinho ao abrir, baixa só o que mudou e aplica na próxima vez que for aberto.
- **Aviso do Windows** ("O Windows protegeu o computador"): clique em *Mais informações* e depois em *Executar assim mesmo*. O instalador não tem assinatura digital.
